# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work.
Harassment, discrimination, and personal attacks are not tolerated, in the repo or in
any project space.

Report unacceptable behavior to **ramanareddy1098@outlook.com**. Reports are handled
confidentially, and the maintainer will respond as promptly as they can.
